# Не твой перевод — полный пакет сайта

Обучающий квест для 10 класса, ориентир — 10 минут. Версия 2.

## Запуск

- Без установки: откройте `offline.html` в браузере. Этот файл содержит всю игру.
- Для редактирования: `index.html` + папка `assets` (стили и JavaScript).
- Для локального сервера при установленном Python: из этой папки запустите `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.
- На телефоне предпочтительна ссылка на размещённый сайт: встроенные просмотрщики HTML иногда не выполняют JavaScript.

## Размещение

Это статический сайт: серверная логика, база данных, API-ключи, npm и сборка не нужны. Загрузите `index.html` и папку `assets` в корневую папку статического хостинга. Также можно разместить `offline.html` под именем `index.html` — это самостоятельная версия. Не смешивайте оба варианта под одним именем.

В архив также включён `.nojekyll` для GitHub Pages. Инструкция GitHub Pages: создайте репозиторий, загрузите содержимое папки (не сам ZIP), откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку / (root), затем сохраните. После успешного развёртывания адрес появится на этой странице. Названия элементов интерфейса могут меняться; официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site . Для доступа из России выберите доступный вашей школе статический хостинг и проверьте ссылку в школьной сети.

## Состав

- index.html — главная страница сайта.
- assets/style.css — адаптивное оформление.
- assets/game.js — все сюжеты и логика игры.
- offline.html — полный автономный HTML.
- TEACHER.md — проведение занятия и ключи.
- SOURCES.md — официальные источники.
- .nojekyll — совместимость со статической публикацией GitHub Pages.

## Данные и функции

Ответы находятся только в памяти текущей вкладки. Нет регистрации, аналитики, внешних шрифтов, трекеров и отправки результатов. Обновление страницы сбрасывает игру. Итог можно скачать TXT или распечатать. Сохранение общего результата класса и кабинет учителя не входят в пакет. Сам хостинг может вести стандартные журналы обращений.

Таймер не блокирует игру после 10 минут. Пауза, памятка и учебный звонок останавливают его. Звук необязателен и синтезируется браузером. Все истории вымышлены, звонок представлен текстом; реальные банковские операции невозможны.

## Редактирование

Меняйте `scenarios` в assets/game.js и стили в assets/style.css. После изменения модульной версии отдельно обновите offline.html: это самостоятельная копия, она не подтягивает файлы assets автоматически. Перед занятием проверьте старт, выборы, обе ветки первого кейса, финал, скачивание и печать на целевых устройствах.

## Проверка

Проверены синтаксис JavaScript и программные маршруты прохождения. Визуальная проверка в настоящем браузере при подготовке пакета не была доступна.
